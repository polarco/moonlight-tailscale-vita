# Security policy

## Supported version

Security fixes currently target the latest published version.

## Reporting

Do not open a public issue containing private keys, pairing certificates,
public endpoints tied to personal infrastructure, or unsanitized logs.

Report vulnerabilities through GitHub's private vulnerability reporting for
this repository. Include a minimal reproduction and affected version, but
replace operational addresses and keys with documentation examples.

If a WireGuard private key or Moonlight pairing credential is exposed, rotate
it before sending any report.
